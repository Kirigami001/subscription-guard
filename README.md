# SubTrack — Управление подписками

Веб-приложение для централизованного отслеживания, анализа и управления регулярными цифровыми подписками.

Разработано в рамках цикла лабораторных работ по дисциплине **«Frontend-разработка веб-приложений» / «Full-stack разработка» (Лабораторная работа №4)**.

## 🛠️ Стек технологий

- **Фреймворк:** React 18
- **Инструмент сборки:** Vite
- **Маршрутизация (Routing):** React Router DOM v6

## 📄 Реализованные страницы (6 страниц)

1. `/` — **Главная (Dashboard)**: Общая сумма расходов в месяц/год, сводные карточки метрик, сетка активных подписок.
2. `/subscriptions` — **Мои подписки**: Полный каталог всех подписок с поиском по названию и фильтрацией по статусам и категориям.
3. `/add` — **Добавить подписку**: Интерактивная форма добавления нового сервиса с валидацией полей.
4. `/subscription/:id` — **Детали подписки**: Развернутая карточка сервиса, расчет годовой стоимости, модуль обнаружения неиспользуемых сервисов (*Unused Subscription Detection*), управление статусом.
5. `/stats` — **Статистика**: Графическое распределение расходов по категориям и полугодовая динамика затрат.
6. `/profile` — **Профиль пользователя**: Данные аккаунта, состав авторов проекта и системные настройки (валюта KZT ₸, правила уведомлений).

## 🧩 Переиспользуемые компоненты (Reusable Components)

- `Navbar.jsx` — Верхнее навигационное меню с логотипом, ссылками на страницы и мобильным гамбургер-меню.
- `Footer.jsx` — Подвал с копирайтом, списком авторов и быстрыми ссылками.
- `Layout.jsx` — Единый макет-обертка (`<Navbar />` + `<Outlet />` + `<Footer />`).
- `SubscriptionCard.jsx` — Карточка подписки с отображением бренда, цены, периода, статуса и кнопками действий.
- `Button.jsx` — Универсальный кнопочный компонент с вариантами `primary`, `secondary`, `danger`, `outline`.
- `Input.jsx` — Стилизованное поле ввода с меткой и валидацией.

## 📱 Адаптивный дизайн (Responsive Design)

Реализован с использованием Media Queries в `src/index.css`:
- **Мобильные устройства (`max-width: 768px`):** Карточки выстраиваются в 1 колонку, верхнее меню трансформируется в бургер.
- **Планшеты (`769px - 1024px`):** Сетка карточек в 2 колонки.
- **Десктоп (`>= 1025px`):** Полноразмерная сетка на 4 колонки.

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone https://github.com/<ваш-логин>/subscription-app.git
cd subscription-app
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm run dev
```

4. Откройте приложение в браузере по адресу:
```text
http://localhost:5173
```
