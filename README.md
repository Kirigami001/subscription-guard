# SubTrack — Управление подписками

Веб-приложение для централизованного отслеживания, анализа и управления регулярными цифровыми подписками.

Разработано в рамках цикла лабораторных работ по дисциплине **«Frontend-разработка веб-приложений» / «Full-stack разработка» (Лабораторная работа №4)**.

- **Авторы проекта:** Айяна, Даулет, Дидар, Темирлан (МУИТ)
- **Преподаватель:** Zhanibek Sydykbek
- **Город / Год:** Алматы, 2026

---

## 🛠️ Стек технологий

- **Frontend:** React 18, React Router DOM v6, Vite (`vite.config.js` с proxy `/api` → `http://127.0.0.1:3001`)
- **Backend:** Node.js (встроенные модули `node:http`, `node:crypto` scrypt/SHA-256, `node:sqlite`)
- **База данных:** SQLite (`subscription-app/server/data/subtrack.sqlite`, таблицы `users`, `sessions`, `subscriptions`)
- **Аутентификация:** Регистрация/вход, хеширование паролей scrypt, HttpOnly SameSite cookie, серверные сессии и изоляция данных пользователей
- **Стилизация:** Адаптивный CSS с Media Queries (`index.css`), поддержка светлой и тёмной темы
- **Дизайн-система:** Макеты Figma из Лабораторной работы №3 (палитра `#1E3A8A`, `#10B981`, `#EF4444`)

## 📄 Реализованные страницы (7 страниц)

1. `/login`, `/register` — **Авторизация и регистрация**: Создание аккаунта и вход с серверной проверкой и cookie-сессией.
2. `/` — **Главная (Dashboard)**: Месячный/годовой эквивалент расходов, сводные метрики, уведомления `/api/insights` о ближайших списаниях на 7 дней, сетка подписок.
3. `/subscriptions` — **Мои подписки**: Полный каталог всех подписок пользователя с поиском по названию и фильтрацией по статусам и категориям.
4. `/add` — **Добавить подписку**: Интерактивная форма добавления нового сервиса с валидацией и сохранением в SQLite.
5. `/subscription/:id` — **Детали подписки**: Развернутая карточка сервиса, расчет годовой стоимости, пауза/возобновление, отмена и удаление подписки.
6. `/stats` — **Статистика**: Распределение расходов по категориям (с пересчетом годовых тарифов в месячный эквивалент) и прогноз регулярных расходов.
7. `/profile` — **Профиль пользователя**: Данные аккаунта, состав авторов проекта и системные настройки (валюта KZT ₸, правила уведомлений).

## 🧩 Переиспользуемые компоненты (Reusable Components)

- `Navbar.jsx` — Верхнее навигационное меню с логотипом, ссылками на страницы, кнопкой выхода, переключением темы и мобильным гамбургер-меню.
- `Footer.jsx` — Подвал с копирайтом, списком авторов и быстрыми ссылками.
- `Layout.jsx` — Единый макет-обертка (`<Navbar />` + `<Outlet />` + `<Footer />`).
- `SubscriptionCard.jsx` — Карточка подписки с отображением бренда, цены, периода, статуса и кнопками действий.
- `Button.jsx` — Универсальный кнопочный компонент с вариантами `primary`, `secondary`, `danger`, `outline`.
- `Input.jsx` — Стилизованное поле ввода с меткой и валидацией.

## 📱 Адаптивный дизайн (Responsive Design)

Реализован с использованием Media Queries в `src/index.css`:
- **Мобильные устройства (`max-width: 768px`):** Карточки выстраиваются в 1 колонку, верхнее меню трансформируется в бургер.
- **Планшеты (`769px - 1024px`):** Сетка карточек в 2 колонки.
- **Десктоп (`>= 1025px`):** Полноразмерная сетка на 4 колонки.

## 🚀 Установка и запуск (Node.js 22.13+ / 24+)

1. Перейдите в папку приложения и установите зависимости:
```bash
cd subscription-app
npm install
```

2. Запустите Backend (терминал №1, в папке `subscription-app`):
```bash
npm run server
# или: node server/index.js
```
API поднимется на `http://127.0.0.1:3001`, база данных автоматически создастся в `subscription-app/server/data/subtrack.sqlite` (в Git не коммитится).

3. Запустите Frontend (терминал №2, в папке `subscription-app`):
```bash
npm run dev
```

4. Откройте приложение в браузере:
```text
http://localhost:5173
```
Проверка работоспособности API и SQLite: `http://127.0.0.1:3001/api/health` → `{"ok":true,"database":"sqlite"}`.
