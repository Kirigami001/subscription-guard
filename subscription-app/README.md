# SubTrack — Управление подписками (Full-Stack)

Веб-приложение для централизованного отслеживания, анализа и управления регулярными цифровыми подписками на **React + Node.js + SQLite**.

Разработано в рамках цикла лабораторных работ по дисциплине **«Frontend-разработка веб-приложений» / «Full-stack разработка»**.

## ✨ Что нового в обновлении (Было → Стало)

- **Хранение данных в SQLite:** вместо статического массива в памяти и браузерного `localStorage` используется серверная БД SQLite (`server/data/subtrack.sqlite`, таблицы `users`, `sessions`, `subscriptions`) с внешними ключами и автомиграциями.
- **Серверная авторизация и безопасность:** пароли хешируются через `scrypt` с солью (`timingSafeEqual`), сессии хранятся на сервере по `SHA-256` хешу в `HttpOnly; SameSite=Lax` cookie, данные изолированы по `user_id`, добавлен rate limiting (`HTTP 429`) и защита от path traversal.
- **Стартовые примеры подписок:** при регистрации нового аккаунта и первом входе в пустой аккаунт автоматически загружаются 8 примеров с актуальными датами, а при `< 3` подписок доступна кнопка **«Загрузить примеры»**.
- **Полный CRUD и продление:** добавление, поиск и фильтрация (включая `cancelled`), полное редактирование карточки, кнопка **«Оплачено (+1 мес / год)»**, пауза/отмена и удаление с проверкой календарных дат на сервере.
- **Аналитика и экспорт:** корректный расчёт месячного эквивалента (`yearly / 12`), настраиваемый горизонт ближайших списаний (`1–30` дн.), рекомендации по экономии (`GET /api/insights`), сохранение настроек профиля (`PATCH /api/profile`) и экспорт в **CSV (UTF-8 BOM)** для Excel.
- **Единый запуск и туннель:** команда `npm run dev` (`dev.mjs`) одновременно запускает Backend (`3001`) и Frontend (`5173`), а `npm start` раздаёт собранный `dist/` и `/api` с одного порта `3001` для быстрого подключения временного туннеля.

## 🛠️ Стек технологий

- **Frontend:** React 18, React Router DOM v6, Vite (`vite.config.js` с proxy `/api` → `http://127.0.0.1:3001`)
- **Backend:** Node.js 22.13+ / 24+ (встроенные модули `node:http`, `node:crypto`, `node:sqlite`)
- **База данных:** SQLite (`server/data/subtrack.sqlite`, в Git не коммитится)
- **Стилизация:** Адаптивный CSS с Media Queries (`src/index.css`), поддержка светлой и тёмной темы

## 📄 Реализованные страницы (7 маршрутов)

1. `/login`, `/register` — **Авторизация и регистрация**: Создание аккаунта и вход с серверной проверкой и `HttpOnly` cookie-сессией.
2. `/` — **Главная (Dashboard)**: Месячный/годовой эквивалент расходов, оценка экономии, уведомления `/api/insights` о ближайших списаниях, рекомендации и сетка подписок.
3. `/subscriptions` — **Мои подписки**: Каталог с поиском, фильтрацией по статусам (`Активные`, `На паузе`, `Пробные`, `Отменённые`) и категориям, экспорт CSV.
4. `/add` — **Добавить подписку**: Форма создания подписки с валидацией и сохранением в SQLite.
5. `/subscription/:id` — **Детали подписки**: Расчёт годовой стоимости, редактирование, продление даты оплаты, пауза/возобновление, отмена и удаление.
6. `/stats` — **Статистика**: Распределение расходов по категориям (в месячном эквиваленте), прогноз трат, экономия и скачивание CSV-отчёта.
7. `/profile` — **Профиль пользователя**: Настройки имени, срока напоминаний (`1–30` дн.) и детектора редких подписок, список авторов.

## 🚀 Установка и запуск (Node.js 22.13+ / 24+)

1. Перейдите в папку приложения и установите зависимости:
   ```bash
   cd subscription-app
   npm install
   ```

2. Запустите проект **одной командой** (автоматически поднимет и Backend на `3001`, и Frontend на `5173`):
   ```bash
   npm run dev
   ```
   *(Раздельный запуск при необходимости: `npm run server` и `npm run client`.)*

3. Откройте приложение в браузере:
   ```text
   http://localhost:5173
   ```
   Проверка API и SQLite: `http://127.0.0.1:3001/api/health` → `{"ok":true,"database":"sqlite"}`.

### Временный публичный доступ (туннель для демонстрации)
1. Запустите единый production-сервер (`dist/` + API + SQLite на порту `3001`):
   ```bash
   npm start
   ```
2. Во втором терминале откройте временный туннель:
   ```bash
   npm run tunnel
   # или без установки cloudflared:
   npx localtunnel --port 3001
   ```
